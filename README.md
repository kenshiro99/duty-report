# สมุดปฏิบัติหน้าที่ (Duty Report)

ระบบบันทึกการปฏิบัติหน้าที่ประจำวันและรายงานสำหรับผู้บริหาร รองรับการใช้งานทั้งบนคอมพิวเตอร์ แท็บเล็ต และสมาร์ตโฟน ออกแบบมาสำหรับการใช้งานคนเดียวโดยเฉพาะ เข้าใช้งานได้ทันที ไม่ต้องล็อกอิน ไม่ต้องตั้งค่าฐานข้อมูล และไม่ต้องเชื่อมต่อ Google Drive

## คุณสมบัติเด่น (Features)

- **เข้าใช้งานได้ทันที (ไม่ต้องล็อกอิน):** เปิดเว็บปุ๊บ บันทึกงานได้ทันที เหมาะสำหรับใช้งานส่วนบุคคล
- **ไม่ต้องมี Google Drive หรือเซิร์ฟเวอร์:** ข้อมูลและรูปภาพบันทึกลงในฐานข้อมูลเบราว์เซอร์ (`IndexedDB`) ของเครื่องคุณโดยตรง ปลอดภัย ทำงานแบบออฟไลน์ได้ 100%
- **ส่งรายงานให้ผู้บริหารง่ายในคลิกเดียว:** กดปุ่ม **"📄 ส่งรายงาน HTML ให้ผู้บริหาร"** ระบบจะแปลงรูปภาพทั้งหมดเป็น Base64 แล้วฝังรวมเป็นไฟล์เดี่ยว (เช่น `รายงานผู้บริหาร-2026-09-24.html`) ส่งให้ผู้บริหารทาง LINE หรืออีเมล ผู้บริหารเปิดดูได้ทันทีแบบออฟไลน์โดยไม่ต้องต่อเน็ต และไม่มีปุ่มแก้ไข/ลบ จึงปลอดภัยสูงสุด
- **ระบบรูปภาพอัตโนมัติ:** แนบรูปภาพภารกิจได้สูงสุด 6 รูปต่อรายการ พร้อมระบบย่อขนาดภาพอัตโนมัติ ช่วยประหยัดพื้นที่จัดเก็บและเปิดดูได้รวดเร็ว
- **สำรองและกู้คืนข้อมูลได้ตลอดเวลา:** มีปุ่ม **"💾 สำรองข้อมูล"** และ **"📂 นำเข้าข้อมูล"** (JSON) สำหรับย้ายเครื่องหรือบันทึกเก็บไว้
- **โฮสต์ฟรีบน GitHub Pages:** นำไฟล์ทั้งหมดขึ้น GitHub แล้วเปิดใช้งาน GitHub Pages เพื่อเข้าใช้งานได้จากทุกอุปกรณ์ ทุกที่ ทุกเวลา

## สถาปัตยกรรมระบบ (Architecture)

```
[ผู้ใช้งาน] ---> [GitHub Pages หรือ เปิดไฟล์ในเครื่อง] ---> [ฐานข้อมูลเบราว์เซอร์ IndexedDB]
                                                                        │
                                                     [กดปุ่ม ส่งรายงาน HTML]
                                                                        ▼
                                                   [ไฟล์รายงานเดี่ยว รวมรูปในตัว]
                                                                        │
                                                              [ส่งต่อให้ผู้บริหาร]
```

## วิธีนำขึ้น GitHub Pages (โฮสติ้งฟรี)

1. เข้าสู่ระบบ [github.com](https://github.com) แล้วกด **New repository**
2. ตั้งชื่อว่า `duty-report` (เลือกเป็น Public)
3. อัปโหลดไฟล์ในโฟลเดอร์นี้ขึ้นไป (`index.html`, `app.js`, `style.css`, `favicon.svg`)
4. ไปที่ **Settings > Pages > Branch: main > / (root)** แล้วกด **Save**
5. รอ 1 นาที จะได้ URL เช่น `https://<ชื่อผู้ใช้ของคุณ>.github.io/duty-report/` เปิดใช้งานได้ทันทีจากทุกที่!
